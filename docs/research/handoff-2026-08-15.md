# Handoff — Eve state and next decisions

**Date:** 2026-08-15

## Current state

Eve is a runnable durable root agent with one HTTP channel and 15 resolved tools.
`pnpm run info` reports zero diagnostics and no declared subagents, schedules,
connections, or agent-packaged skills.

- **Model:** `eve-orchestrator` through the Agency Gateway, with gateway-owned
  Cloudflare fallback and a 256K context window.
- **Host access:** `bash`, `read_file`, `write_file`, `glob`, and `grep` run on the
  host rather than the sandbox.
- **Search:** Tavily, Exa, Brave, and Firecrawl remain distinct tools behind shared
  provider contracts. All four have passed live Eve runtime checks.
- **Media:** image generation, text-to-speech, and transcription use the Agency
  Gateway's image and audio lanes.
- **Observability:** PostHog OpenTelemetry and Sentry are configured.
- **Outbound messaging:** one fixed-owner tool delegates to SMTP, Resend, or
  AgentMail adapters and validates Verizon email gateway constraints.

## Communication evidence

The transport abstraction is shipped, but the delivery experiment did not produce
a reliable communication surface:

- AgentMail accepted messages to Verizon's documented email gateways, and its API
  labeled them `sent`; neither reached the handset.
- A manual Gmail message to the same Verizon text address arrived immediately.
- The Resend domain `mail.navinhill.com` has sending and receiving enabled but was
  still pending verification at the last live read-back.
- The Resend Chat SDK channel is documented in nearby research files but is not
  installed or configured.

Provider acceptance must not be reported as recipient delivery.

`pnpm sync` refreshes the clean local sibling checkout. The `eve`,
`technical-writing`, and `gh-pr-description` project skills are symlinked into that

## Decisions already made

1. Gateway routing owns root-model fallback; Eve uses one static alias.
2. Host-native shell and file access is the intentional local-development posture.
3. Search providers remain separate model-facing tools but share adapter contracts.
4. Outbound transport and destination formatting are separate concerns.
5. Communication work takes precedence over voice when it creates a reliable
   user-facing surface.

## Open strategic directions

### Bidirectional communication

Complete the Resend Chat SDK path after domain verification. Production use needs
a durable Chat SDK state adapter, a public webhook, signature verification,
inbound deduplication, threading, and an end-to-end reply test. The in-memory state
adapter is development-only.

### Google Workspace connections

A Google OAuth foundation could unlock Gmail, Calendar, and Drive. Treat OAuth
consent, refresh-token storage, identity, and the first focused APIs as one owning
slice rather than isolated tools.

### Memory

Eve already has durable sessions. Define global, project, thread, and ephemeral
retrieval boundaries before adding another memory store; otherwise two persistence
systems will have ambiguous ownership.

### Voice and avatar

ElevenLabs and Anam remain a viable shell around Eve, but voice adds turn-taking,
streaming, and media complexity. It should follow a reliable text communication
surface unless voice itself becomes the selected product priority.

### Additional tools, connections, and subagents

Add them for observed workflows. The current adapter seams are healthy; expanding
the model-facing surface without a concrete use case would add selection and
maintenance cost.
